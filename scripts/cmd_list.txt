## Slurm CMD

### Show & Request GPU allocation
```
sinfo
sinfo -o "%N %G"
gpuavail
srun --pty --partition=gpu --gres=gpu:a100:1 --time=00:10:00 --mem=32G --ntasks=1 /bin/bash
```

## Shwo Jobs status
```
squeue -u $USER
```

### Show SU usage
```
myproject
myproject -j [account_id]
```

### Load software
```
module spider packageName
module load packageName/version
```

### Standard modules
```
module load WebProxy
module load Miniconda3/23.10.0-1
module load GCC/11.3.0
module load CUDA/11.8.0
```

### Remove software
```
module purge
module unload packageName
```

```
sbatch submit_job.sh

```
